Connect Medplum

  1. In Medplum, go to Admin → Project → Clients → New. Set Launch URI to {{ launch_url }} and Redirect URI to {{ redirect_uri }}.
  2. Start this app with SMART_CLIENT_ID=<client id> (add SMART_CLIENT_SECRET if Medplum gives you one).
  3. Create a synthetic test Patient in Medplum with an identifier: system {{ mrn_system }}, value = one of the MRNs above, or seed them all with python scripts/seed_medplum.py (see docs/medplum.md).
  4. Open that patient in Medplum → Apps tab → click this app. Medplum asks you to Choose scope ({{ smart.scope }}), and then this dashboard opens on that patient.

⚠️ Synthetic patients only. This app has no login, and real MRNs must never be mapped to study data until IRB approval and authentication are in place.
